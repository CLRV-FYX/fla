# FLA 宝塔面板部署（不用 Docker）

分工：**宝塔**负责 Nginx、SSL 证书、防火墙；**FLA** 由 `bt.sh` 安装依赖，并注册为系统服务（开机自启，崩溃后自动重启）。

## 1. 宝塔软件商店

- 安装 **Nginx**（任意稳定版）。
- 不需要 MySQL 和 PHP。FLA 自带 SQLite 数据库。

## 2. 下载代码并安装（宝塔 →「终端」）

```bash
mkdir -p /www/wwwroot/fla && cd /www/wwwroot/fla
curl -fL https://codeload.github.com/CLRV-FYX/fla/tar.gz/refs/heads/arena/01a0d6ff-fla | tar -xz --strip-components=1
bash bt.sh install
```

`install` 会自动完成：

- 安装 LibreOffice（PPT/Word 转换）、ffmpeg、中文字体；
- 创建 Python 虚拟环境并安装依赖；
- 注册 `fla` 服务，放行 8306 和 1935 端口。

最后会显示「✔ 应用已就绪」和初始管理员密码。

> 如果提示没有 Python 3.9+：到 宝塔 → 网站 → Python项目 → **Python版本管理** 安装 3.11，然后重新运行 `bash bt.sh install`。

配置文件是 `deploy/.env`，可以修改端口、管理员密码、数据目录等。改完执行 `bash bt.sh restart`。

## 3. 宝塔添加网站（反向代理）

1. 宝塔 → 网站 → **添加站点**：域名填 `t.clrv.top` 和 `t.fyx.best`（一行一个），PHP 版本选「纯静态」。
2. 进入站点 → **配置文件**，把 `server { ... }` 里自带的 `location` 段全部删掉，换成下面这段，然后保存：

```nginx
    client_max_body_size 2048m;
    proxy_read_timeout 600s;
    proxy_send_timeout 600s;

    location / {
        proxy_pass http://127.0.0.1:8306;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Host $host;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_buffering off;
        proxy_request_buffering off;
    }
```

3. 站点 → **SSL** → Let's Encrypt，申请证书并打开「强制 HTTPS」。
4. **任意域名都能访问**：宝塔 → 网站 → 顶部 **默认站点** → 选中这个站点。之后用 IP 或者其它解析过来的域名访问，也会进入 FLA。

## 4. 防火墙

- 宝塔 → **安全**：放行 `80`、`443`、`1935`（iPhone 整屏投屏）。8306 只在本机内部使用，不用对外放行。
- **云服务器控制台的安全组**也要放行 TCP `80`、`443`、`1935`。

## 5. 日常命令（在 /www/wwwroot/fla 目录执行）

| 操作 | 命令 |
|---|---|
| 更新到最新版 | `bash bt.sh pull` |
| 重启 / 停止 | `bash bt.sh restart` / `bash bt.sh stop` |
| 状态 + 版本号 | `bash bt.sh status` |
| 查看日志 | `bash bt.sh logs` |
| 重置 admin 密码 | `bash bt.sh passwd 新密码` |

网页底部会显示 `FLA v版本 · 更新时间`，可以用来确认更新是否成功。

## 6. 从旧服务器迁移数据（可选）

旧服务器的数据在 Docker 卷里：

```bash
docker run --rm -v deploy_fla-data:/d -v /root:/o alpine tar -czf /o/fla-data.tgz -C /d .
```

把 `fla-data.tgz` 传到新服务器，然后：

```bash
cd /www/wwwroot/fla && bash bt.sh stop
mkdir -p data && tar -xzf /root/fla-data.tgz -C data
bash bt.sh start
```

卷名不一定是 `deploy_fla-data`，可以用 `docker volume ls | grep fla` 查看。
